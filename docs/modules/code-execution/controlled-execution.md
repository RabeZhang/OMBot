# Controlled Code Execution

**验证状态**

- 实现状态：已实现第一版受控执行环境
- 产品评分：3/5
- 架构评分：4/5
- 主要源码：`src/code-execution`

**核心理念**

- 当前目标是受控执行环境，而不是强安全沙箱。
- 代码执行入口必须统一、可审计、可审批、可限制资源。
- 受控执行与真正 OS 级沙箱是两回事，文档中必须明确区分。

**当前实现方式**

当前对外工具：

- `code_run`

当前支持语言：

- `python`
- `typescript`

当前实现边界：

- 独立运行目录
- 独立 `HOME / TMPDIR`
- 最小环境变量
- 输入文件显式注入
- artifact 收集
- 超时与 `ulimit` 资源限制
- 使用宿主机 `python3 / tsx`

当前限制：

- 不是强安全沙箱
- 无 OS 级文件系统隔离
- 无硬禁网
- 解释器仍然来自宿主机
